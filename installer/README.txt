Nugz Support Tool Installer

Double-click Install-Nugz.cmd.

The installer will:
- Request administrator permission
- Install Support.exe and KeyGen.exe to Program Files\Nugz Support Tool
- Create Start Menu shortcuts
- Leave generated support.key files out of the package

To uninstall, run:
PowerShell -ExecutionPolicy Bypass -File "C:\Program Files\Nugz Support Tool\Uninstall-Nugz.ps1"
