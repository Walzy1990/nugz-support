# Global Deployment

This folder is published by `.github/workflows/pages.yml` through GitHub Pages.

Repository:

`https://github.com/Walzy1990/nugz-support`

Expected public URL:

`https://walzy1990.github.io/nugz-support/`

## One-time GitHub setup

1. Open repository Settings -> Pages.
2. Set Source to GitHub Actions.
3. In Settings -> Actions -> General, allow actions and reusable workflows.
4. Set workflow permissions to Read and write permissions.
5. Push this folder and the workflow to the `main` branch.
6. Wait for the `Deploy Nugz website` workflow to finish successfully.

The site is static and globally served by GitHub Pages. No database or server command is required.
